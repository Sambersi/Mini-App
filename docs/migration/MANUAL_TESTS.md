# Журнал изменённых сценариев

На 2026-11-27 код БД не менялся. Ни один сценарий ниже не отмечен как перенесённый или проверенный. Это начальная очередь для подготовки проверок. Точные значения и динамические кнопки уточняются по фактическому меню на тестовом стенде.

## Формат записи после каждого изменения

Обязательные поля: ID; дата и коммит; изменение; команда и алиасы; роль и тип чата; начальные данные; последовательность кнопок с видимыми названиями и callback; обработчики/сервис/таблицы; результат на экране и в БД; автопроверки и их доказательства; ручной результат пользователя; связанные дефекты. Команды, которые только читают изменённые данные, тоже включать.

Статусы: запланировано → код изменён → автопроверки пройдены → готово к ручной проверке → проверено пользователем. Непроверенные или заблокированные ветви указывать отдельно. Предлагать пользователю для проверки только подготовленные сценарии.

Исходники могут содержать выключенные команды: не выдавать их за доступные функции без проверки маршрутизации.

## Правила ручного прогона

Использовать тестовую БД и тестовых игроков; исходные суммы фиксировать до действия. Проверять не только текст успеха, но и повторное открытие профиля/меню, состояние второго игрока и запись операции. Сетевые выплаты, рассылки и настоящие покупки не имитировать молча как пройденные. Для каждого падения сохранять ID сценария, коммит, шаг, ожидаемый и фактический результат без секретов и персональных данных.
