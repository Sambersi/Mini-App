## Проверки и особенности совместимости

- 32 локальных теста прошли, 0 пропущено. Включены потеря точности, BLOB и смешанные типы SQLite, повреждение/пропуск/добавление строк, откат при сбое, повторный импорт и запрет активной/чужой базы.
- На реальном сервере выявлен автоматический разбор JSON драйвером mysql2. Для точной сверки установлен jsonStrings=true; исходный JSON не пересобирается после чтения.
- Сверка обнаружила дробные даты регистрации в SQLite INTEGER-колонке. Версия схемы 002 сохранила их через DECIMAL(30,12); сравнение десятичных значений не использует округление Number. Версия 001 не переписывалась.
- Оба расхождения остановили прогон и откатили соответствующую таблицу/рабочую проекцию. После исправлений весь импорт и повторная сверка прошли на реальной MariaDB.
